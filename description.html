Close the main window and keep Thunderbird in the system tray. Close to Tray leaves Thunderbird running when you close its main window. A tray icon stays visible. Click the icon to hide the open window or show that same window again. Opening Thunderbird from the application menu or a pinned icon shows that window too. Key features:
  • Closing the main window hides Thunderbird instead of quitting.
  • The tray icon shows or hides that same window.
  • Quit from the tray menu, or with File → Quit.
Installation:
  1. In Thunderbird, open the menu and choose Add-ons and Themes.
  2. Click the gear icon and choose Install Add-on From File…, then select the .xpi. Or type Close to Tray in the search field, open this add-on, and choose Add to Thunderbird.
  3. When Thunderbird asks for access, choose Add.
This add-on runs on Linux with Thunderbird 128 through 158. The tray icon needs Python 3 with PyGObject (gi) and a StatusNotifier tray, such as KDE Plasma or Xfce. The permission covers the whole application because the add-on has to intercept closing the main window. Settings Open the add-on card in Add-ons and Themes and choose its preferences.
  • When Thunderbird is closed, move it to the system tray — while this is on, the tray icon stays visible. Closing the main window leaves Thunderbird running. Turn it off and closing the main window quits Thunderbird.
If the desktop has no StatusNotifier tray, the page says a tray icon is not available. The tray icon
  • Click the icon while the main window is open to hide it.
  • Click the icon while the window is hidden to show that same window.
  • Choose Quit Thunderbird from the tray menu to exit.
